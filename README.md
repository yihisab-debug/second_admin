# MiniBank Admin

Отдельное Flutter-приложение для сотрудника банка. Работает с тем же
PHP API и той же базой `mini_bank`, что и клиентское приложение.

## Возможности

- **Обзор** — показатели банка и журнал действий администратора.
- **Клиенты** — поиск, фильтр, блокировка и разблокировка пользователей.
- **Кредиты** — добавление, изменение, отключение и удаление кредитных программ.
- **Депозиты** — то же самое для программ вкладов.

## Запуск

1. Скопировать файлы из папки `api/` в `htdocs/minibank/api/`
   (`config.php`, `login.php`, `overview.php` заменяют старые).
2. Один раз открыть в браузере `http://localhost/minibank/api/admin_setup.php`,
   затем **удалить этот файл** с сервера.
3. Скопировать `pubspec.yaml` и папку `lib/` в проект `admin`.
4. Выполнить:

```
flutter pub get
flutter run
```

## Адрес сервера

Задаётся в `lib/core/api.dart`, поле `Api.baseUrl`:

| Где запускается приложение | Адрес |
|---|---|
| Windows / Web / Desktop | `http://localhost/minibank/api` |
| Эмулятор Android | `http://10.0.2.2/minibank/api` |
| Телефон в той же Wi-Fi сети | `http://192.168.x.x/minibank/api` |

## Вход

| Поле | Значение |
|---|---|
| Телефон | `+7 700 000 00 00` |
| Пароль | `admin1234` |

Обычный клиент в это приложение не войдёт: после проверки пароля сервер
возвращает `is_admin`, и без прав администратора экран входа отдаёт ошибку.
Права заново проверяются при каждом запуске приложения, поэтому отозванный
доступ перестаёт работать сразу.
