# MiniBank · модуль администратора

Добавлена роль администратора с тремя привилегиями:

1. добавлять, изменять и удалять **кредитные программы**;
2. добавлять, изменять и удалять **депозитные программы**;
3. **блокировать и разблокировать** пользователей банка.

---

## 2. Установка базы данных

Откройте в браузере один раз:

```
http://localhost/minibank/api/admin_setup.php
```

Скрипт добавит в таблицу `users` колонки `is_admin`, `is_blocked`,
`blocked_reason`, `blocked_at`, создаст таблицу `admin_log` и заведёт
учётную запись администратора.

**После успешного запуска удалите `admin_setup.php` с сервера.**

Альтернативный путь — выполнить в phpMyAdmin файл `sql/04_admin.sql`,
а затем назначить админа вручную:

```sql
UPDATE users SET is_admin = 1 WHERE phone = '77000000000';
```

## 3. Вход в панель

| Поле | Значение |
|---|---|
| Телефон | `+7 700 000 00 00` |
| Пароль | `admin1234` |

Обычные клиенты приложение видят по-прежнему: панель открывается только
если сервер вернул `is_admin = true`. PIN-код администратору не нужен.

## 4. Как это работает

**Права.** Каждый админ-эндпоинт начинается с `currentAdmin()`. Функция
проверяет токен и колонку `is_admin`; если клиент обычный — ответ 403
«Раздел доступен только администратору». Проверка выполняется на сервере,
поэтому подменить экран в приложении бесполезно.

**Блокировка.** При блокировке в `users` записывается причина и время,
а все токены клиента удаляются — он моментально выходит из приложения на
всех устройствах. Дальше `currentUser()` в `config.php` отдаёт 403 на
любой запрос, а `login.php` не пускает по паролю. Клиенту создаётся
уведомление с причиной. Деньги и история операций сохраняются.
Заблокировать себя или другого администратора нельзя.

**Услуги.** Кредитные и депозитные программы лежат в таблицах `creditors`
и `deposit_products`. Клиентские эндпоинты (`creditors.php`,
`deposit_products.php`) отдают только строки с `is_active = 1`, поэтому
новая услуга видна клиентам сразу после сохранения, а «снятая с продажи»
исчезает из каталога, не ломая уже оформленные договоры. Если услугой уже
кто-то пользуется, удаление автоматически превращается в отключение —
внешние ключи и история остаются целыми.

**Журнал.** Каждое действие администратора пишется в `admin_log` и
показывается на вкладке «Обзор».
